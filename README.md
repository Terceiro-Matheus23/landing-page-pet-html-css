# landing-page-pet-html-css

Projeto desenvolvido durante meus estudos de desenvolvimento web para praticar HTML e CSS.

## Sobre o projeto

Landing page criada para uma página de cuidados com animais, utilizando uma estrutura simples de navegação, seção de apresentação, imagem, textos e botão de ação.

## Tecnologias utilizadas

- HTML5
- CSS3

## Objetivo

Praticar a criação de interfaces web utilizando HTML e CSS, trabalhando com estrutura, posicionamento, espaçamento, tipografia e organização dos elementos.
